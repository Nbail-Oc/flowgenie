# FlowGenie

> Intelligent workflow automation and agent orchestration platform

---

## 🚀 Overview

No-code/low-code workflow engine empowering users to compose agentic pipelines, API triggers, and LLM reasoning steps.

---

## 🛠️ Tech Stack

`TypeScript` • `React` • `Node.js` • `Tailwind CSS`

---

## ✨ Key Features

- **Visual node-based workflow builder**
- **Custom LLM prompts and decision routing nodes**
- **REST and webhook integration triggers**

---

## 📦 Getting Started

### Prerequisites

Ensure you have the appropriate runtime installed (Node.js 18+ or Python 3.10+ depending on project stack).

### Installation

```bash
# Clone the repository
git clone https://github.com/Nbail-Oc/flowgenie.git

# Navigate into the project directory
cd flowgenie
```

### Setup & Run

- If this is a **Node.js / Next.js** project:
  ```bash
  npm install  # or pnpm install / yarn
  npm run dev
  ```

- If this is a **Python / FastAPI** project:
  ```bash
  python -m venv venv
  source venv/bin/activate  # On Windows: .\venv\Scripts\activate
  pip install -r requirements.txt
  python main.py  # or uvicorn main:app --reload
  ```
